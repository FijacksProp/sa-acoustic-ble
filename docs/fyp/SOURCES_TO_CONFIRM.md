# Source Verification Notes

This file records the sources currently used in the report and how they support the project. The formal APA 7 reference list is maintained in `REFERENCES.md`.

## Verified Academic Sources

1. Getreuer, Gnegy, Lyon, and Saurous (2018)
   - DOI: https://doi.org/10.1109/TMM.2017.2766049
   - Use: Supports near-ultrasonic communication using consumer speakers and microphones.
   - Project relevance: Acoustic beacon design and limitations.

2. Jia et al. (2022)
   - DOI: https://doi.org/10.3390/s22197345
   - Use: Supports smartphone-based near-ultrasonic proximity sensing.
   - Project relevance: Acoustic signal as short-range copresence evidence.

3. Ramirez et al. (2021)
   - DOI: https://doi.org/10.3390/s21155181
   - Use: Discusses BLE RSSI measurement for indoor positioning.

4. Puckdeevongs et al. (2020)
   - DOI: https://doi.org/10.3390/info11060329

## Plagiarism Control Notes

- Do not copy abstracts or long passages from papers into the report.
- Use each source to support an idea, then paraphrase in original wording.
- Keep direct quotations rare and short.
- Cite the author and year whenever an idea, finding, or comparison comes from a source.
- Keep implementation claims tied to what has actually been built and tested.
